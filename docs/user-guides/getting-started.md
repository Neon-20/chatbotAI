# Getting Started with DomusAI

Welcome to DomusAI! This guide will help you get up and running with our AI-powered chat interface in just a few minutes.

## 🎯 What is DomusAI?

DomusAI is a comprehensive AI chat platform that allows you to:
- Chat with multiple AI models (OpenAI, Claude, Gemini, and more)
- Organize conversations in workspaces
- Upload and discuss files with AI
- Use pre-built prompts and suggestions
- Collaborate with team members

## 🚀 First Steps

### 1. Account Setup

1. **Sign Up**: Visit the DomusAI homepage and click "Sign Up"
2. **Verify Email**: Check your email and click the verification link
3. **Complete Profile**: Fill in your display name and bio
4. **Choose Plan**: Select your subscription plan (if applicable)

### 2. Initial Configuration

After signing up, you'll be guided through the setup process:

#### Profile Setup
- **Display Name**: How you'll appear to other users
- **Bio**: Brief description about yourself
- **Profile Picture**: Upload an avatar (optional)
- **Profile Context**: Information the AI can use to personalize responses

#### API Keys (Optional)
If you have your own API keys, you can add them for:
- OpenAI
- Anthropic Claude
- Google Gemini
- Azure OpenAI
- Mistral AI

> **Note**: API keys are optional. DomusAI provides hosted models you can use immediately.

### 3. Your First Chat

1. **Access Your Workspace**: You'll automatically have a "Home" workspace
2. **Start Chatting**: Click the chat input at the bottom
3. **Try Suggestions**: Click on any suggestion tile to get started
4. **Upload Files**: Drag and drop files to discuss them with AI

## 🏢 Understanding Workspaces

Workspaces help you organize your conversations by project, topic, or team:

- **Home Workspace**: Your personal space (created automatically)
- **Team Workspaces**: Shared spaces for collaboration
- **Project Workspaces**: Organized by specific projects

### Creating a New Workspace

1. Click the workspace switcher in the sidebar
2. Select "Create New Workspace"
3. Fill in the details:
   - **Name**: Descriptive workspace name
   - **Description**: What this workspace is for
   - **Privacy**: Public or private
   - **Default Model**: Preferred AI model
   - **Instructions**: Custom instructions for the AI

## 💬 Chat Interface Basics

### Starting a Conversation

1. **New Chat**: Click the "+" button in the sidebar
2. **Select Model**: Choose your preferred AI model
3. **Type Message**: Enter your question or prompt
4. **Send**: Press Enter or click the send button

### Using Suggestion Tiles

The homepage features suggestion tiles for common tasks:
- **Rewrite Text**: Improve and paraphrase content
- **Summarize**: Create concise summaries
- **Translate**: Convert text between languages
- **Code Review**: Analyze and improve code
- **Email Draft**: Create professional emails
- **Meeting Notes**: Organize meeting information

### File Uploads

DomusAI supports various file types:
- **Documents**: PDF, DOCX, TXT
- **Spreadsheets**: XLSX, CSV
- **Images**: PNG, JPG, GIF
- **Code**: Most programming languages

To upload files:
1. Drag and drop files onto the chat
2. Or click the attachment button
3. Files are processed and ready for discussion

## ⚙️ Basic Settings

### Chat Settings

Access chat settings via the gear icon:
- **Temperature**: Controls AI creativity (0-1)
- **Context Length**: How much conversation history to include
- **Model Selection**: Switch between AI models
- **System Prompt**: Custom instructions for the AI

### Profile Settings

Manage your profile in the user menu:
- **Personal Information**: Update name, bio, avatar
- **API Keys**: Add or update your API keys
- **Preferences**: Theme, language, notifications
- **Security**: Password, two-factor authentication
