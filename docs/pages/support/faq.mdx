# Frequently Asked Questions

Find answers to the most common questions about DomusAI.

## General Questions

### What is DomusAI?

DomusAI is an advanced AI-powered chat interface that allows you to interact with multiple AI language models in a single platform. It provides workspace organization, file handling, and enterprise-grade features for individuals and teams.

### Which AI models are supported?

DomusAI supports a wide range of AI models including:
- **OpenAI**: GPT-4, GPT-4 Turbo, GPT-3.5 Turbo, GPT-4 Vision
- **Anthropic**: Claude 3 Opus, Claude 3 Sonnet, Claude 3 Haiku
- **Google**: Gemini Pro, Gemini Pro Vision, PaLM 2
- **Azure OpenAI**: Enterprise versions of OpenAI models
- **Mistral AI**: Mistral 7B, Mixtral 8x7B, Mistral Medium/Large
- **Others**: Groq, Perplexity, OpenRouter, Local models via Ollama

### Is DomusAI free to use?

DomusAI offers multiple pricing tiers:
- **Free Tier**: Limited usage with hosted models
- **Pro Tier**: Higher limits and additional features
- **Enterprise**: Custom limits and enterprise features
- **Self-Hosted**: Use your own infrastructure and API keys

### How do I get started?

1. Sign up for an account at [domusai.com](https://domusai.com)
2. Complete the onboarding process
3. Start chatting with AI models immediately
4. Optionally add your own API keys for unlimited usage

## Account & Authentication

### How do I reset my password?

1. Go to the login page
2. Click "Forgot Password"
3. Enter your email address
4. Check your email for reset instructions
5. Follow the link to set a new password

### Can I change my email address?

Currently, email addresses cannot be changed after account creation. Please contact support if you need to change your email.

### How do I delete my account?

<Callout type="warning">
  Account deletion is permanent and cannot be undone.
</Callout>

To delete your account:
1. Go to Profile Settings
2. Scroll to the bottom
3. Click "Delete Account"
4. Confirm the deletion
5. All your data will be permanently removed

### What happens to my data when I delete my account?

When you delete your account:
- All chats and messages are permanently deleted
- Uploaded files are removed from storage
- Workspaces you own are deleted
- Shared workspaces remain but your access is revoked
- The deletion cannot be undone

## Usage & Features

### How many messages can I send?

Message limits depend on your plan:
- **Free**: 50 messages per month
- **Pro**: 1,000 messages per month
- **Enterprise**: Custom limits
- **Own API Keys**: Unlimited (subject to provider limits)

### What file types can I upload?

DomusAI supports various file types:
- **Documents**: PDF, DOCX, TXT, RTF, MD
- **Spreadsheets**: XLSX, CSV
- **Images**: PNG, JPG, JPEG, GIF, WebP, SVG
- **Code**: Most programming languages
- **Maximum size**: 10MB per file

### How does file processing work?

When you upload a file:
1. Content is extracted and processed
2. Text is split into chunks for better AI understanding
3. Vector embeddings are created for semantic search
4. Files are stored securely in your workspace
5. You can then ask questions about the file content

### Can I use my own API keys?

Yes! You can add your own API keys in Profile Settings:
1. Go to Profile Settings
2. Navigate to API Keys section
3. Add keys for supported providers
4. Test the connection
5. Start using unlimited AI models

### How do workspaces work?

Workspaces help organize your conversations:
- **Home Workspace**: Your personal space (created automatically)
- **Team Workspaces**: Shared with colleagues
- **Project Workspaces**: Organized by specific projects
- Each workspace can have custom settings and instructions

### Can I share conversations?

Yes, you can share conversations in several ways:
- **Public Links**: Share read-only links to conversations
- **Workspace Sharing**: Invite others to your workspace
- **Export**: Download conversations as PDF, Markdown, or JSON

## Technical Questions

### Is my data secure?

DomusAI takes security seriously:
- All data is encrypted in transit and at rest
- Row Level Security (RLS) ensures data isolation
- API keys are encrypted and never logged
- Regular security audits and updates
- GDPR and SOC 2 compliant

### Where is my data stored?

- **Database**: Supabase (PostgreSQL) with global distribution
- **Files**: Secure cloud storage with encryption
- **Backups**: Automated daily backups with point-in-time recovery
- **Location**: Data centers in US, EU, and Asia-Pacific

### Can I export my data?

Yes, you can export your data at any time:
- **Individual Chats**: Export as PDF, Markdown, or JSON
- **All Data**: Request complete data export from Profile Settings
- **Files**: Download original files from the Files section
- **Format**: Choose from multiple export formats

### Does DomusAI work offline?

DomusAI requires an internet connection for:
- AI model interactions
- Real-time synchronization
- File uploads and processing

However, some features work offline:
- Viewing cached conversations
- Basic interface navigation
- Offline file viewing

### What browsers are supported?

DomusAI works best on modern browsers:
- **Chrome**: Version 90+
- **Firefox**: Version 88+
- **Safari**: Version 14+
- **Edge**: Version 90+
- **Mobile**: iOS Safari, Chrome Mobile

## Billing & Subscriptions

### How does billing work?

Billing is based on your subscription plan:
- **Monthly**: Billed every month
- **Annual**: Billed yearly with discount
- **Usage-based**: Pay for what you use (Enterprise)
- **API Keys**: No additional charges when using your own keys

### Can I change my plan?

Yes, you can upgrade or downgrade at any time:
1. Go to Account Settings
2. Click "Manage Subscription"
3. Select your new plan
4. Changes take effect immediately

### What payment methods are accepted?

We accept:
- Credit cards (Visa, MasterCard, American Express)
- PayPal
- Bank transfers (Enterprise plans)
- Cryptocurrency (Bitcoin, Ethereum)

### Do you offer refunds?

- **Monthly plans**: No refunds for partial months
- **Annual plans**: Prorated refunds within 30 days
- **Enterprise**: Custom refund policies
- **Unused credits**: Carried over to next billing cycle

## Troubleshooting

### Why are my messages not sending?

Common causes and solutions:
1. **Check internet connection**
2. **Verify API key configuration** (if using own keys)
3. **Check message limits** (free tier restrictions)
4. **Try refreshing the page**
5. **Clear browser cache and cookies**

### Files won't upload - what should I do?

Troubleshooting steps:
1. **Check file size** (max 10MB)
2. **Verify file type** is supported
3. **Try a different browser**
4. **Disable browser extensions**
5. **Check internet connection stability**

### The interface is slow or unresponsive

Performance optimization:
1. **Close unnecessary browser tabs**
2. **Clear browser cache**
3. **Disable browser extensions**
4. **Try incognito/private mode**
5. **Check system resources**

### I'm getting API errors

API error solutions:
1. **Check API key validity**
2. **Verify provider account status**
3. **Check rate limits**
4. **Try a different model**
5. **Contact support if issues persist**
